# Public Preview Scope

This repository contains the inspectable software framework for FungalRiskMeta.

Included:

- Public-preview CLI skeleton.
- Minimal toy input files.
- A lightweight smoke test for the public preview CLI.

Excluded from this public preview:

- Research resources.
- Full analysis workflows.
- Real metagenomic read data.
- Validation result tables.
- Unpublished study materials.

The complete research repository remains private during manuscript preparation. Collaborator and reviewer access can be granted separately when appropriate.
